# DataForge 运营治理与 Agent Trace 闭环设计

日期：2026-08-11  
状态：已确认，直接实施

## 目标

本轮不是增加更多孤立页面，而是让现有“设置、成本管理、风险与优化、运行记录”形成可演示、可验证的闭环：

- 组织级管理员能力同时识别受信任的 Entra 应用角色和配置的租户 Owner OID，不再因用户还拥有其他低权限工作区而误判。
- DeepSeek 连接、纳入治理、模型路由、模型选择与请求级估算价格使用同一事实源。
- 成员只有在同租户且经过企业身份策略验证时显示姓名和邮箱；外部或未验证身份继续使用匿名引用。
- 身份与访问成为设置页的直接入口，明确展示 Graph 连接、管理员同意、组搜索和组到工作区映射状态。
- 成本页的时间、部门、Agent、模型筛选作用于所有摘要、趋势、排名和状态，不允许顶部卡片保留旧口径。
- 趋势图把日期放在坐标轴下方，缓存命中使用独立可读颜色，悬浮层不被相邻卡片裁切。
- 运行记录在同一页面切换到 Trace 详情，先显示本地步骤，再按需补充 Azure Monitor Span；风险和成本证据可以深链到相同详情。
- External Agent 的注册、运行时 Agent ID、OpenTelemetry 根 Span 和 Foundry Trace 使用同一稳定标识。

## 权限与身份边界

组织级敏感操作使用统一能力判定：可信 Easy Auth 身份，且满足配置的 Entra 应用角色或 `DF_FINOPS_TENANT_OWNER_OIDS`。工作区级操作只校验目标工作区，不再要求用户在所有已授权工作区都是管理员。

组治理仅创建 DataForge “Entra 组 → 工作区角色”映射，不在应用内创建、修改或删除 Entra 目录组。Graph 令牌不足时返回明确的 `consent_required` 或 `unavailable`，不能伪装成已连接。

邮件配置属于组织级能力；测试发送和保存配置使用同一管理员能力。自动预算提醒仍由独立开关控制，不能因为测试邮件成功就隐式开启生产通知。

## DeepSeek 与计价闭环

Provider 密钥保持只写。连接测试成功后，管理员可以把 Provider 纳入治理；审计事件必须使用允许的显式原因码并成功持久化。只有已治理、连接健康、模型目录有效的部署进入 Agent 模型选择器。

价格目录支持 DeepSeek V4 Flash/Pro。可靠匹配时返回估算成本和价格版本；无法匹配时显示“未计价”并给出映射入口，不得使用其他模型价格兜底。

## 成本口径与前端行为

所有查询缓存键包含工作区、时间范围、部门、Agent 和模型。筛选变化立即进入“更新中”并保留上次可用布局，成功后所有 KPI 与图表一起替换。后端响应继续标记 available、partial、unavailable 或 estimated，前端不填造接口缺失值。

趋势图绘图区和横轴标签区分离：基线属于绘图区，日期位于基线下方；柱高按真实最大值比例计算。Tooltip 使用视口定位和足够层级，不受父卡片裁切。

## Trace 与 External Agent

新增 `GET /api/runs/{run_id}/trace-view?include_remote=1`。服务端先校验当前工作区 `run.read`，再从受信任 Run 记录获取 trace ID，绝不接受浏览器提交任意 trace/workspace 作为查询授权依据。

响应只包含白名单技术字段：trace/span/parent ID、状态、时间、耗时、Agent/模型、Token、缓存、估算成本、工具名称、证据引用和规范化错误类别。Prompt、Completion、工具原始参数/结果、邮箱、Entra OID、密钥、Provider 原始响应和内部错误正文必须在服务端丢弃。

运行记录中的“查看 Trace”在同一内容区切换详情；返回时恢复筛选、分页和滚动位置。JSON 固定高度、不自动换行，支持纵向和横向滚动，浅色背景使用深色文本。

External Agent 注册不在应用启动路径执行。部署步骤单独完成 register/verify，并核对 Foundry External Agent 的 `otel_agent_id` 与 DataForge 根 Span 的 `gen_ai.agent.id`。

## 验收门禁

- 组织 Owner 可配置并测试管理员邮件；普通成员不可用。
- DeepSeek 可完成连接、纳入治理、选择模型和价格映射，且审计可回读。
- 同租户验证成员显示邮箱，未验证身份仍匿名。
- 身份与访问入口可见，Graph 状态真实，组搜索与组映射可执行或给出可操作的管理员同意提示。
- 切换模型后顶部成本、调用、Token、趋势和排名共同变化，请求包含模型筛选。
- 日期在横轴下方，缓存颜色和 Tooltip 可读，390px 与桌面无裁切。
- 运行记录可进入/返回 Trace；技术 JSON 无敏感字段且可双向滚动。
- Python、Node、Vite、Playwright、`git diff --check` 和密钥扫描通过。
- 候选环境健康、登录态验收通过后才切换生产，并保留上一健康 revision 作为回滚目标。
