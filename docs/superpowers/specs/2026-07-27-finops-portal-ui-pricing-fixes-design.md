# FinOps Portal UI 与 GPT-5.6 计价修复设计

## 目标

修复运营管理中四个可见问题，同时保持现有指标、审计、请求事实和历史成本逻辑不变。

## 交互与布局

- 趋势图不再常驻显示无图例的运营事件圆点；事件数量保留在对应柱体的悬停详情中。
- 请求证据抽屉从全局顶栏下方展开，遮罩也不覆盖顶栏；桌面端保持右侧抽屉，移动端保持全宽。
- 指标说明问号与指标名称组成紧凑的行内标题组，问号是可聚焦按钮。
- 只有问号悬停、键盘聚焦或说明框本身悬停时显示指标说明；整张指标卡不再触发说明框。
