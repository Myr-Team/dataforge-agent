# DataForge 运营管理

DataForge 运营管理面向 IT 与财务人员，用同一个入口解释成本、效能、价值与风险。它不复制工作区、数据资产、会话、分析产物或运行记录；运行记录仍负责逐次 Agent 执行与返回会话，运营管理只承接跨请求的经营判断。

客户界面统一使用“统一入口”“请求对账”“运行追踪”等业务术语，不直接显示底层网关产品名。底层服务标识只用于受控的工程排障，不作为客户指标标题。

## 四个运营问题

1. **运营总览**：当前调用、Token、估算成本、成功率、时延、缓存命中和统一入口覆盖是否正常？
2. **成本分析**：成本由哪些部门、专案、Agent 和模型产生，预算与计价覆盖处于什么状态？
3. **效能与 ROI**：本期投入、使用和产出有什么变化，哪些收益只是情景测算，哪些业务结果已经独立验证？
4. **风险与优化**：哪些成本、体验、效率或治理风险应优先处理，证据是什么，可以保存怎样的整改草案？

## ROI 的情景与验证边界

- “情景测算”来自人工维护的工时价值、避免损失、实施成本等参数，以及平台已记录的模型估算成本。
- 情景结果可用于方案比较，但不等于已经实现的 ROI；页面始终将其标记为 `estimated / 情景测算`。
- “已验证 ROI”只使用经过业务负责人独立确认的结果事件。没有验证结果时显示“结果待验证”，不会把情景数值升格为已实现回报。
- 价值桥、证据成熟度和单位效能趋势保留服务端返回的状态。缺失值不会补零，微额单位成本保留足够小数位，避免非零成本显示为 `$0.00`。

## 从风险到整改草案

风险页按业务影响、证据置信度与受影响请求范围展示四个治理域，并提供互相联动的风险矩阵、优先事项、优化组合与代表证据。

处理路径为：

`风险信号 → 影响范围 → 代表请求证据 → 建议 → 保存整改草案 → 人工复核`

- 不使用不可解释的复合风险分数。
- 每个风险只关联自己的请求引用、缓存状态、时延、错误类别和可见结果摘要。
- 保存草案只写入白名单字段，不接受任意脚本、XML、URL 或资源 ID。
- 保存草案不会提交、批准或执行生产变更；配置版本冲突返回 409，重新加载后必须再次人工复核。
- `DF_FINOPS_ACTIONS_ENABLED` 默认保持 `0`。即使草案可提升，也只会生成独立审批流程中的动作草案。

## 刷新与缓存

- 浏览器内存缓存新鲜期为 5 分钟，可用旧结果窗口为 30 分钟；不写入 localStorage 或其他持久化浏览器存储。
- 服务端查询缓存同样使用 5 分钟 fresh、30 分钟 stale-while-revalidate 窗口，并按租户、权限、工作区、筛选条件和数据域隔离。
- 页面每 10 分钟只刷新当前可见页签。后台隐藏时不刷新，恢复可见后只检查当前页签是否到期。
- 在 5 分钟内往返 ROI 与风险页不会重复请求；手动刷新只作用于当前页签。
- 后台更新失败时保留最近一次成功结果并显示陈旧提示，不用整页骨架覆盖可用内容。
- 进入运营管理后空闲预取 ROI 决策；用户悬停、键盘聚焦或触摸页签时可以预取对应数据。
- 读取、预取和定时刷新都不会自动调用分析 Agent。Agent 只在用户明确咨询或受控后台分析任务中运行。

## 请求证据与隐私

- 请求证据默认显示稳定的业务名称，例如 `Commerce · 批量分析 · 慢响应`；技术 ID 只在折叠详情中出现。
- 代表证据可显示用户业务请求和最终可见回答，但不采集或展示 system prompt、provider 原始响应、密钥、原始身份和内部错误正文。
- 应用事件与统一入口日志通过 correlation 对账，同一次调用的 Token 或成本不会相加两次。
- 高基数的 Agent、人员和工作区下钻来自应用事件；统一入口指标保持低维度。

## 数据与执行边界

- Azure SQL 保存请求事实、聚合、映射、价目表、异常、分析结论、策略、审批和动作状态。
- Redis 只缓存有界查询结果，不是事实来源。
- 当前成本来自 DataForge 价目表估算，不代表 Azure 或其他云平台的实际账单。
- 所有接口从可信认证声明推导 tenant，并在服务端收窄 workspace 范围。
- 未经明确批准，不切换生产流量，不启用治理执行。

## 候选环境门禁

生产启用前仍需在零流量候选环境完成：

- 多 Agent、多模型成功、4xx、5xx、慢请求与缓存 miss→hit 样本；
- 统一入口 correlation 与 DataForge 请求证据联查；
- 一笔价目表 revision 手算成本与页面一致；
- member 无法读取未授权工作区或组织级人员明细；
- 一条异常完成触发、确认与解决；
- 一条生产动作完成异人审批、候选执行、验证与回滚；
- Python、Node、Vite、Playwright 全量回归，以及登录态桌面和移动端截图验收。

浏览器 mock 和本地自动化只证明前端契约与交互，不替代真实 Redis、数据库、认证或已部署候选环境证据。
