# DataForge 成本与计价方法

版本：2026-08-11

## 请求级估算成本 {#estimated-cost}

请求级估算成本把已记录的输入、输出、缓存输入和推理 Token，分别按当前激活的模型价目修订版进行计算，再按部门、工作区、Agent 和模型聚合。

公式：估算成本 = 输入 Token × 输入单价 + 输出 Token × 输出单价 + 缓存输入 Token × 缓存单价 + 推理 Token × 推理单价。

判断边界：该值用于运营归因和预算预警，不代表云平台实际账单；不存在的 Token 分类保持未记录，不能补零后假装完整。

## 价目覆盖与未计价 {#price-coverage}

价目覆盖率表示请求所使用的模型或 deployment 能否可靠关联到已激活价目修订版。新模型、别名变化或缺少官方价格时，请求应保留为“未计价”。

公式：价目覆盖率 = 已计价请求数 ÷ 全部请求数。

判断边界：未计价不等于免费，也不能用相似模型价格自动替代；应由管理员复核模型标识、币种、计价单位和生效日期。

## 预算阈值与提醒 {#budget-threshold}

预算提醒使用当前统计周期内的已计价估算成本，与成员或工作区预算比较。提醒可以帮助管理员提前复核高成本来源。

公式：预算消耗率 = 当前周期估算成本 ÷ 预算金额。

判断边界：提醒不自动限流，不替代财务结算，也不能在计价覆盖不足时把缺失成本视为零。
