# 深圳选址 FinOps 演示口径

本资料仅说明 `demo-corpus` 的合成深圳选址演示。其场景为虚构企业对候选点位进行资料检索、市场研究、可行性分析和证据审阅，不代表客户生产遥测或业务结论。

- 所有演示请求、运行和引用都带有 `synthetic_demo` 来源；模型路线是合成投影，不能描述为供应商已观测路线。
- 价格只在存在精确官方价目键和版本时计入；未映射请求显示为未计价，而不是零成本。
- DataForge 结果缓存和供应商 Token 缓存是不同证据层。重复选址分析的 miss 到 hit 只证明结果缓存链路；供应商未上报的缓存必须显示为不可用。
- 风险卡来自现有规则扫描对合成请求事实的计算。证据引用可定位到请求和同一运行 Trace，但不代表生产告警。
- ROI 情景是估算；配对流程指标是待业务确认的合成测量。`演示验证结果 · 合成数据` 仅说明独立审阅的合成流程结果，绝不构成生产已验证 ROI。

当前数值必须以实时 API 返回的账本、Trace 和证据状态为准；本资料不能替代请求级事实。
