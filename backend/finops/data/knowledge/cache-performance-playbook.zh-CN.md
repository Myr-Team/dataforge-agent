# DataForge 缓存与性能优化手册

版本：2026-08-11

## 缓存命中与估算节省 {#cache-savings}

结果缓存命中表示相同工作区、相同分析输入和兼容策略版本复用了既有结果。命中、未命中、绕过和未记录必须分开统计。

公式：缓存估算节省 = 可避免输入 Token × 对应模型输入单价；命中率 = 命中请求 ÷ 可缓存请求。

判断边界：命中率不是节省金额。只有存在命中证据、可避免 Token 和有效价目时才能估算节省；绕过缓存不应计入未命中。

## P50、P95 与长尾响应 {#latency-percentiles}

P50 表示中位体验，P95 用于发现少量慢请求形成的长尾。定位时应同时按模型、路由、缓存状态和调用类型下钻。

公式：P95 为已记录延迟排序后的第 95 百分位位置。

判断边界：样本不足时不形成稳定异常；缓存命中带来的延迟改善应与同类请求比较，不能跨不同任务复杂度直接归因。
